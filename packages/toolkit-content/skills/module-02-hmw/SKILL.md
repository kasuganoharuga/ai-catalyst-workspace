# How Might We Framing

Use this skill to turn evidence and observations into focused opportunity questions.

## Inputs

- Problem evidence
- Target customer segment
- Current alternatives
- Observed friction

## Output

Create a prioritised set of How Might We questions, opportunity framing notes, and exploration constraints.
