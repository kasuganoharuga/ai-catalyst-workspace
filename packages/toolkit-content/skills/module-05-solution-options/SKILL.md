# Solution Options

Use this skill to explore multiple product or workflow directions without prematurely locking into one.

## Inputs

- Problem statement
- Customer constraints
- Existing alternatives
- Founder capabilities

## Output

Create a solution option set, trade-off comparison, recommended first wedge, and risks by option.
