# Ideal Customer Profile

Use this skill to narrow broad customer hypotheses into a practical early ICP.

## Inputs

- Potential customer groups
- Pain intensity signals
- Buying or adoption context
- Existing interview notes

## Output

Create a primary ICP, secondary ICP candidates, disqualification criteria, and interview targeting notes.
