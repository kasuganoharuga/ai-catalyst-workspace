# Module 00: Workspace Setup

Prepare the founder context before running the AI Catalyst Founder Toolkit.

## When to Use

Use this module before starting the workflow, especially when founder notes are scattered across documents, pitch decks, calls, or early research.

## Required Inputs

- Founder background
- Company or idea summary
- Known constraints
- Existing notes or artefacts

## Expected Outputs

- Workspace context brief
- Input checklist
- Module readiness map
