# Module 06: Validation Plan

Translate the chosen wedge into focused experiments and evidence goals.

## When to Use

Use this module when the founder has a preferred solution option and needs a practical validation plan.

## Required Inputs

- Preferred solution option
- Top assumptions
- Available channels
- Time and budget constraints

## Expected Outputs

- Validation plan
- Experiment backlog
- Evidence thresholds
- Founder action plan
